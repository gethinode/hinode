{{- /* Applies title case to a string, honoring Hugo's `titleCaseStyle` setting. Accepts rendered HTML: tags and character entities pass through untouched, so inline markup such as `` from a markdown backtick survives intact. The casing is applied once to the concatenated text content and then mapped back onto the original by rune position, which keeps stopword handling correct across tag boundaries. Character entities contribute a single space to the plain string used for casing, rather than nothing. Omitting them entirely would join the words on either side of the entity, so the word right after it would never be treated as starting a word (e.g. `the cat sat` would case to `The cat Sat` instead of `The Cat Sat`). The entity itself is still always re-emitted verbatim in the output — only the *casing pass* sees a space stand-in for it — and because a space cases to a space, the one-rune width keeps the positional mapping back onto the original tokens exact. Inline code and keyboard input are never adjusted: the text inside a `` or `` element is always emitted exactly as authored, so "Inline test `case`" renders as "Inline Test `case`". Their contents still take part in the casing pass as ordinary words, so the words around such a span keep correct stopword and first-word handling (`the `foo` of it` stays `The `foo` of It`). Only the final text-run emission is skipped for runes inside these elements. Words listed in `site.Params.main.titleCaseExceptions` are canonical spellings, such as `AI`, `dbt`, `iOS` or `npm`. Every whole-word occurrence matching an entry case-insensitively is rewritten to the entry, so lowercase-authored acronyms that `title` would capitalize (`npm` → `Npm`) keep their spelling, and entries can also force capitals (`ai` → `AI`). A match written entirely in capitals, such as a deliberately shouted `NPM`, is left alone. The rewrite is the final step (see utilities/TitleCaseExceptions.html), after the authored-capital restoration below, so it also corrects sources that arrive capitalized, such as Hugo's own taxonomy term titles (`dbt` → `Dbt`). Entries must be plain words. `titleCaseExceptions` must be a list. A scalar (e.g. a bare string, which is what a TOML author typing `"npm"` instead of `["npm"]` produces, and what Hugo hands through when the param is set via an `HUGO_PARAMS_MAIN_TITLECASEEXCEPTIONS` environment variable) is rejected with `errorf` naming the param and the value received, rather than being ranged over — which would otherwise fail later with an opaque "range can't iterate over ..." template execution error. Casing may only ever add capitals, never remove them: after `title` and the exception restoration run, every rune the author wrote in uppercase is restored over whatever the filter produced there. AP style lowercases stopwords ("and", "in", "on", "to", …) regardless of how they were written, so an all-caps heading such as `AN INTRODUCTION TO THE THING` would otherwise come back with its stopwords lowercased, and an authored acronym or keyword like `AND` would lose its case too. This restoration is a single pass over the whole cased string — not per text token in the mapping loop — run on `$result` in the fast path and on `$cased` in the slow path (before the rune split, since the length guard below compares `$cased` against `$plain`). Menu entries can follow a casing preference of their own. Title case suits headings and page titles in editorial style, while many interface conventions write controls such as menu items in sentence case, so a site may want both at once. A caller rendering a navigation entry - a navbar menu item or a sidebar row - passes `menu`, and the text is then cased by `site.Params.main.titleCaseMenu` instead of `titleCase`. When `titleCaseMenu` is omitted it mirrors `titleCase`, so a site that does not set it renders exactly as before. `exact` still opts out either way. @param {string} text Plain string or rendered HTML. @param {page} page Page supplying `.Params.exact`. Optional when `exact` is passed. @param {bool} exact Optional. Overrides `page.Params.exact` for callers holding no page. @param {bool} menu Optional. Marks the text as a navigation entry, cased by `main.titleCaseMenu` (which defaults to `main.titleCase`). @returns {string} The title-cased text, or the input unchanged when title casing is disabled, opted out of, or cannot be applied safely. */ -}} {{- $text := .text -}} {{- $result := $text -}} {{- $exceptions := site.Params.main.titleCaseExceptions | default slice -}} {{- if not (hasPrefix (printf "%T" $exceptions) "[]") -}} {{- errorf "Expected list value in site parameters: main.titleCaseExceptions (got %T: %v)" $exceptions $exceptions -}} {{- $exceptions = slice -}} {{- end -}} {{- $exact := false -}} {{- if isset . "exact" -}} {{- $exact = .exact -}} {{- else -}} {{- with .page -}}{{- $exact = .Params.exact -}}{{- end -}} {{- end -}} {{- $enabled := site.Params.main.titleCase -}} {{- if .menu -}} {{- with site.Params.main -}} {{- if isset . "titlecasemenu" -}}{{- $enabled = index . "titlecasemenu" -}}{{- end -}} {{- end -}} {{- end -}} {{- if and $enabled (not $exact) $text -}} {{- if not (or (strings.Contains $text "<") (strings.Contains $text "&")) -}} {{/* Fast path: no markup and no entities, so the filter can be applied directly. */}} {{- $result = title $text -}} {{/* Never lowercase an authored capital, then restore canonical spellings (see above). */}} {{- if ne $text (lower $text) -}} {{- $pr := split $text "" -}} {{- $cr := split $result "" -}} {{- if eq (len $pr) (len $cr) -}} {{- $m := slice -}} {{- range $i, $r := $pr -}} {{- $m = $m | append (cond (eq $r (upper $r)) $r (index $cr $i)) -}} {{- end -}} {{- $result = delimit $m "" -}} {{- end -}} {{- end -}} {{- with $exceptions -}} {{- $result = partial "utilities/TitleCaseExceptions.html" (dict "text" $result "entries" .) -}} {{- end -}} {{- else -}} {{/* Split into tags, character entities, and text runs. Only the text runs are cased. */}} {{- $tokens := findRE `<[^>]+>|&#?[0-9a-zA-Z]+;|[^<&]+|[<&]` $text -}} {{- $plain := slice -}} {{- range $tokens -}} {{- if and (hasPrefix . "<") (hasSuffix . ">") -}} {{- else if and (hasPrefix . "&") (hasSuffix . ";") -}} {{- $plain = $plain | append " " -}} {{- else -}} {{- $plain = $plain | append . -}} {{- end -}} {{- end -}} {{- $plain = delimit $plain "" -}} {{- $cased := title $plain -}} {{/* Never lowercase an authored capital (see doc block above). Must run before the rune split, since the length guard below compares $cased against $plain. */}} {{- if ne $plain (lower $plain) -}} {{- $pr := split $plain "" -}} {{- $cr := split $cased "" -}} {{- if eq (len $pr) (len $cr) -}} {{- $m := slice -}} {{- range $i, $r := $pr -}} {{- $m = $m | append (cond (eq $r (upper $r)) $r (index $cr $i)) -}} {{- end -}} {{- $cased = delimit $m "" -}} {{- end -}} {{- end -}} {{- with $exceptions -}} {{- $cased = partial "utilities/TitleCaseExceptions.html" (dict "text" $cased "entries" .) -}} {{- end -}} {{- $runes := split $cased "" -}} {{/* The filter only changes case, so lengths must match. If they ever do not, the positional mapping would corrupt the markup — return the input untouched. */}} {{- if eq (len $runes) (len (split $plain "")) -}} {{- $out := slice -}} {{- $pos := 0 -}} {{- $code := 0 -}} {{- range $tokens -}} {{- if and (hasPrefix . "<") (hasSuffix . ">") -}} {{- if findRE `(?i)^<(code|kbd)[\s>/]` . 1 -}} {{- $code = add $code 1 -}} {{- else if and (findRE `(?i)^$` . 1) (gt $code 0) -}} {{- $code = sub $code 1 -}} {{- end -}} {{- $out = $out | append . -}} {{- else if and (hasPrefix . "&") (hasSuffix . ";") -}} {{- $out = $out | append . -}} {{- $pos = add $pos 1 -}} {{- else -}} {{- $n := len (split . "") -}} {{- if gt $code 0 -}} {{- $out = $out | append . -}} {{- else -}} {{- $out = $out | append (delimit (first $n (after $pos $runes)) "") -}} {{- end -}} {{- $pos = add $pos $n -}} {{- end -}} {{- end -}} {{- $result = delimit $out "" -}} {{- end -}} {{- end -}} {{- end -}} {{- return $result -}}
